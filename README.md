# Empathetic AI for Students 

A voice-based study assistant that helps students stay focused and emotionally supported while studying. It listens to how you feel, offers motivational messages when needed, and provides subject notes — all through a simple voice or text interaction.

---

## Project Description

Many students struggle with stress, distraction, or low motivation during study sessions. This project aims to make learning more supportive by combining emotion-aware responses with academic help. The assistant detects emotional cues from speech or text and tailors its replies — offering study notes, reminders, or motivational messages based on how the user feels.

---

##  Features

-  Accepts both voice and text input
-  Detects emotional tone like stress, focus, or confusion
-  Offers motivational messages before academic content (if needed)
-  Fetches study notes using the Wikipedia API
-  Speaks the response aloud with Text-to-Speech
-  Supports simple note-taking and reminders

---

##  Technologies Used

- **Python 3**
- `speech_recognition`
- `pyttsx3`
- `wikipedia`
- `HTML`, `CSS`, `JavaScript` (for user interface)
